# serial-tool v0.1 开发清单：枚举串口

> 目标：程序运行后，打印出这台电脑上所有的 COM 口。
> 预计用时：2-4 个晚上。全程手写，AI 只用来解释概念和报错。

## 第 0 步：环境（半小时）

- [ ] 用 Visual Studio 打开 `D:\Projects\serial-tool\`，新建项目：
  - 模板选「空项目」，语言 C++（但我们写 .c 文件）
  - 位置就选仓库根目录，项目名叫 `serial-tool`
- [ ] 添加 `src/main.c` 到项目（右键源文件 → 添加 → 现有项）
- [ ] 如果 VS 报"预编译头"错误：项目属性 → C/C++ → 预编译头 → 设为「不使用」
- [ ] （可选）装 [com0com](https://sourceforge.net/projects/com0com/) 虚拟串口对——没硬件也能全程开发测试

## 第 1 步：搞懂概念（20 分钟阅读）

先回答自己三个问题（可以问我，也可以搜）：
1. COM 口是什么？它和 USB 转串口（CH340）什么关系？
2. Windows 里"打开一个设备"为什么用 `CreateFile`？（提示：Windows 把设备也当文件）
3. `\\.\COM3` 这个路径为什么要四个反斜杠？（C 字符串转义 + 设备命名约定）

## 第 2 步：实现 list_ports()（核心，1-2 晚）

在 main.c 里写一个函数：

```c
void list_ports(void);   // 打印本机所有 COM 口
```

**实现提示（不是答案）**：用 API `QueryDosDeviceA`，它的用法：

```c
char buf[65536];
DWORD len = QueryDosDeviceA(NULL, buf, sizeof(buf));
// 成功后 buf 里是这样的结构：
// "设备名1\0设备名2\0...\0\0"
//                ^^^^^ 双 \0 表示结束
```

你要做的：
- [ ] 遍历 buf 里每个以 `\0` 分隔的字符串（想想：怎么在循环里移动位置？）
- [ ] 判断设备名是否以 `"COM"` 开头（查一下 `strncmp` 的用法）
- [ ] 是就 `printf` 打出来
- [ ] main() 里调用它，运行看结果

**检验标准**：程序输出的 COM 口数量和「设备管理器 → 端口」里的一致。
（笔记本没接串口设备时可能是 0 个——这本身也是正确结果；装了 com0com 后应该能看到 COM3/COM4 之类）
